# 求助时，怎么说才有人帮
> 关键词：求助、表达、开口、支持

很多同学不是不想求助，是不知道怎么开口。记住三句话模板：

第一句："我遇到一件事，想请你帮帮我。"
——先给对方一个明确的信号：这不是闲聊，我需要帮助。

第二句："事情是……（说事实，一到两句）"
——不用讲得很完整，也不用先讲情绪。事实越具体，对方越知道怎么帮。

第三句："我现在最需要的是……（陪伴/建议/帮我告诉别人/陪我去找老师）"
——明确你要什么，对方才不会只说"加油"。

示例：
"老师，我遇到一件事想请你帮忙。最近班上几个同学总在放学路上堵我。我最需要的是学校能介入一下，我不敢一个人回家了。"

如果面对大人说不出口，可以写纸条、发微信，或者先跟朋友说，让朋友陪你一起去。

如果第一次求助被敷衍（"这有什么大不了的"），换一个人再说。求助不是一次就成功的，但值得坚持。
