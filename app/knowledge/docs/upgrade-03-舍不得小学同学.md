# 舍不得小学同学，心里空落落的
> 关键词：毕业、分离、友谊、告别、初中新朋友

快毕业了，一想到要和相处六年的同学分开，心里空落落的，甚至会偷偷哭——这说明你很重感情，这不是脆弱。

分离焦虑是人之常情。心理学上，人对"失去熟悉的关系"会有真实的悲伤反应，就像失去一件重要的东西。允许自己难过，不用急着说"没关系"。

几件可以做的事：

一，好好告别。可以写一张卡片、拍一张合照、约一次毕业前的聚会。仪式感能帮大脑完成"结束"这件事。

二，把友谊"续约"。和好朋友约定联系方式、约定假期见面、约定上初中后互相分享新学校的事。真正的朋友不会因为换了学校就消失。

三，给新关系留位置。初中会认识新同学，这不是"背叛"老朋友。人的心里可以装下很多人。

四，接受"有些朋友会走远"。这也是成长的一部分，不等于你不好。

如果毕业前情绪低落持续很久、影响到吃饭睡觉，可以跟班主任或心理老师聊聊。
