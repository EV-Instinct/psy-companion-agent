# 任务拆解：把"不想做"变成"现在能做"
> 关键词：拖延、任务拆解、行动、启动

拖延往往不是因为懒，是因为任务在脑子里"太大、太模糊"，大脑本能地想逃。

拆解三步：

一，写下一个让你拖延的任务，比如"复习语文"。

二，问"第一步是什么"，直到答案小到"5分钟能做完"。例如：
复习语文 → 复习古诗词 → 背《XX》前两句 → 读三遍，合上书复述。
最后一步，5分钟就能做。

三，立刻做那"第一步"，做完再决定要不要继续。往往一旦开始，就会做下去——这叫"启动效应"。

两个辅助技巧：
- 两分钟法则：能在两分钟内做完的事，立刻做（收书包、回消息、订正一道题）。
- 给任务设"下限"而不是"上限"：今天至少做5道题，而不是"必须做完50道"。下限能保证开始，开始比完美重要。

如果任务让你焦虑到不敢碰，先做"最不相关但最简单"的部分：整理书桌、把卷子按科目分好。整理的过程也是心理上的"预热"。
