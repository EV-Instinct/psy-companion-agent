# 生气的时候，怎么不伤人也不伤己
> 关键词：生气、愤怒、情绪管理、冷静、表达

生气是身体在"备战"：心跳加快、肌肉紧绷、说话变冲。这时候大脑的理性部分暂时"掉线"，很容易说出后悔的话。

生气的当下，先用"物理方法"降温：

一，离开现场。告诉对方"我现在很生气，先出去一下"，去洗手间用冷水洗脸，或者到走廊走一圈。离开不是逃避，是给大脑降温。

二，数呼吸。吸气4秒、呼气6秒，做五轮。呼气拉长能启动副交感神经，让心率降下来。

三，把话写下来，先不发送。在手机备忘录或纸上写"我现在想说的是……"，写完通常就没那么想骂人了。

冷静之后，再表达。一个万能句式："当______发生的时候，我感到______，我希望______。"比如："你当着同学的面说我笨的时候，我特别难受，我希望你有话私下跟我说。"

生气不代表关系破裂。会生气、也会修复，才是健康的关系。
