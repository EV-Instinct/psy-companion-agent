# 把"大担心"拆成"小问题"
> 关键词：焦虑、任务拆解、具体化、可控

"我担心升学"是一个巨大的、模糊的担心，模糊的东西最让人焦虑，因为大脑不知道该怎么处理它。

把它拆小，焦虑就会变得可操作。方法叫"具体化"：

第一步，写下最担心的一句话，比如"我怕上初中跟不上"。

第二步，连问三个"具体是什么"：
- 怕哪一科跟不上？（数学）
- 数学的哪部分最没底？（应用题）
- 应用题里最怕什么？（读不懂题意）

第三步，针对最后这个具体问题，找一个具体动作：每天做一道应用题，做完用自己的话复述题意。

你会发现，经过三次拆分，"我要完蛋了"变成了"我每天做一道应用题"。前者无法行动，后者今天就能做。

这个方法可以用在任何担心上：怕考不好→怕哪科→怕哪种题→今天练什么；怕交不到朋友→怕什么场合→怕说什么→今天跟谁说一句话。

焦虑不怕被面对，怕的是被含糊地养着。
