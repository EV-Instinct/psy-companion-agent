# 怕上初中跟不上，怎么办
> 关键词：初中、学习压力、跟不上、预习、学习方法

"初中科目变多、进度变快，我会不会跟不上"——这是六年级最常见的担心之一。

先说事实：初中的知识难度确实是台阶式上升的，但学校会安排过渡，老师也会从头讲起。真正拉开差距的，往往不是智商，而是三个习惯：能不能按时完成作业、能不能主动问问题、能不能自己整理错题。

可以提前准备的三件事：

一，练"专注力"，不是提前学。每天能专注25分钟做一件事（不看手机、不走神），比提前学完初一课本更有用。

二，练"整理"。学会用文件夹分科、用错题本记录、用清单管理作业。初中的信息量变大，整理能力就是战斗力。

三，练"开口问"。小学不敢问问题，初中会更吃亏。可以从现在开始，每周至少问老师一个问题——哪怕是很小的问题。

一个小提醒：不要用"提前学完初中课程"来缓解焦虑，那会把暑假变成第三个学期。适度预习（比如看看数学第一章的目录）就够了，剩下的时间用来运动和玩。
