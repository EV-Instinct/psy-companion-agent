# 想加入一个圈子，又怕被拒绝
> 关键词：融入、小团体、社交、勇气、拒绝

看到几个同学聊得很开心，想加入又不敢开口——这种犹豫几乎每个人都经历过。

几个降低难度的方法：

一，从"在旁边"开始。不用一上来就加入对话，可以先在他们附近做自己的事（看书、吃饭），让他们习惯你的存在。

二，找一个"低风险话题"。比如评论一句大家都感兴趣的事："你们也在看那个动画吗？"话题越公共，越不容易被拒绝。

三，帮个小忙。借个笔、递个东西、帮忙占个位置，小互动比长篇自我介绍自然得多。

四，被拒绝也没关系。对方可能只是那天心情不好、或者没听见。一次拒绝不等于"我不受欢迎"。

五，别为了融入改变底线。如果这个圈子要你一起嘲笑别人、一起违反规则，那不叫融入，叫同流。宁可暂时一个人，也不要用伤害别人换归属。

真正的朋友，是让你做自己还愿意跟你在一起的人。
