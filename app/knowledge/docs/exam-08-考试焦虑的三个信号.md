# 考试焦虑的三个信号，你中了几个
> 关键词：考试焦虑、身体信号、想法信号、行为信号、识别

考试焦虑不只是"紧张"，它会从三个地方冒出来。

身体信号：考试前头痛、肚子痛、心跳快、手心出汗、想吐、睡不着、吃不下。有些同学一到考试就"生病"，考完就好，这很可能是焦虑的身体表达。

想法信号：脑子里反复出现"我肯定考不好""考不好就完了""别人都比我强""爸妈会失望"。这些想法有个共同点——把一次考试的结果放大成整个人生的结果。

行为信号：拖延复习、反复检查书包、不想去学校、考试时频繁上厕所、考完不敢对答案。

识别信号之后，可以做两件事：一是给信号"命名"——"我现在心跳快，是焦虑来了，不是我要死了"；二是准备一个"急救包"：三次慢呼吸 + 一句自我提示（"我只要把会做的做对"）+ 一个具体动作（喝口水、转一转笔）。

如果三个信号同时出现，并且持续影响考试，建议找学校心理老师做几次放松训练。焦虑是可以被训练的，不是性格缺陷。
