# 初中和小学，到底哪里不一样
> 关键词：初中、变化、课程、作息、适应

提前知道"会变什么"，能减少一大半的未知恐惧。

课程：科目从语文数学英语为主，变成语数英加政史地生，初二初三还会增加物理化学。书变多、作业变多，需要更强的整理能力。

节奏：小学一节课讲一个知识点，初中一节课可能讲三个。老师不会像小学那样反复提醒"拿出课本"，需要你自己跟上。

关系：同学来自不同小学，朋友圈会重新组合。班主任的管理方式也更接近"自我管理"，不再事事盯着。

评价：除了期末考，还有月考、周测；成绩排名可能不再公开（政策已明确禁止按成绩排名），但竞争感依然存在。

身体：青春期开始，个子、声音、情绪都会变化，这是正常的。

应对的核心是三个"自己"：自己整理（书包、错题、作业清单）、自己提问（不懂就问，不等老师发现）、自己安排（放学后的时间怎么用）。

这些能力不需要提前学完课程，从六年级的现在就可以练。
