# 爸妈总把"好初中"挂在嘴边
> 关键词：父母期待、好初中、压力、沟通、边界

"你要是考不上XX初中，以后就完了"——这句话会让很多六年级同学瞬间紧绷。

先理解一件事：父母说这种话，多半是焦虑的转移，不是真的在给你判刑。他们担心你的未来，但表达方式让你只感受到了压力。

可以尝试的沟通方式：

一，选时机。不要在他们刚说完、你正生气的时候回应。等大家都平静了，比如饭后散步时。

二，用"我"开头。不说"你们别逼我了"，而说"你们一提起好初中，我就特别紧张，晚上会睡不着。我知道你们是为我好，但我需要一点喘息的空间。"

三，给替代方案。比如："我们能不能约定，每周只聊一次升学的事？其他时间我想专心复习。"具体的约定比笼统的抗议更容易被接受。

四，找第三方。如果沟通无效，可以请班主任或你信任的老师帮忙跟父母聊一次。

如果父母的话已经变成羞辱、威胁，或者你因此不想回家，请告诉老师，或拨打12355。你有权利被好好对待。
