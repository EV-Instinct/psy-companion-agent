# 模拟考没考好，其实是好事
> 关键词：模拟考、失利、查漏补缺、心态

模拟考的目的不是排名，是"提前暴露问题"。考得好，说明这部分掌握了；考得不好，说明这张卷子帮你找到了还没掌握的地方——这比中考时才发现的代价小得多。

看待模拟考的三个角度：

一，它是"体检"，不是"判决"。体检发现指标异常，你会庆幸发现得早，而不是觉得自己完了。

二，看"错因"不看"分数"。把错题分成三类：知识不会、方法不对、粗心大意。三类问题的解决方式完全不同——知识不会要补课本，方法不对要问老师，粗心要练检查习惯。

三，关注"进步曲线"而不是"单次波动"。成绩有起伏很正常，一次考试受题目难度、身体状态、心情影响很大。把最近三次的成绩连起来看趋势，比盯着一次分数有用。

如果模拟考后出现持续的情绪低落、不想学习、害怕考试，别自己扛，找老师或心理老师聊聊。心态也是需要练习的能力。
