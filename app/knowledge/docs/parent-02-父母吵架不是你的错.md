# 爸妈吵架，不是你的错
> 关键词：父母吵架、自责、家庭冲突、安全感

很多孩子看到父母吵架，会本能地想"是不是因为我""如果我乖一点他们就不吵了"。这是孩子的"自我中心"思维，不是事实。

请记住三句话：

第一，大人吵架是他们之间的事，原因是他们的沟通方式和压力，不是你的成绩、不是你的错。

第二，你不需要当"调解员"。孩子没有能力也没有责任修复父母的婚姻。你可以说"你们吵架我很难受"，但不必站队、不必传话。

第三，保护自己的安全感。吵架时可以去自己的房间、戴上耳机、找朋友聊聊天；如果吵得很凶甚至有暴力，一定要告诉其他信任的大人（老师、亲戚），必要时报警。

如果父母长期冷战或频繁争吵，你可以找班主任或心理老师聊聊——不是"家丑外扬"，是给自己找一个支撑。

你值得在一个安稳的家里长大。如果暂时没有，也请记得：这不是你的错，你仍然可以好好长大。
