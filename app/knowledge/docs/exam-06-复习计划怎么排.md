# 复习计划怎么排才不慌
> 关键词：复习计划、番茄钟、任务拆解、时间管理

复习慌，往往不是因为时间少，而是因为"不知道从哪开始"。把大任务拆小，是缓解焦虑最有效的办法之一。

方法一：倒推法。先在纸上写下考试日期，往前倒推：还剩几天、每天能复习几小时。再把科目列出来，分配到每一天。不要排满，每天留出1小时"机动时间"处理没完成的部分。

方法二：番茄工作法。25分钟专注做一件事，然后休息5分钟；四个番茄钟后休息15到20分钟。专注的25分钟里，手机放到另一个房间。对六年级学生，也可以从15分钟一个"番茄"开始。

方法三：三件事清单。每天早上只写三件"今天必须完成"的事，按重要性排序。完成一件划掉一件。划掉的动作本身会带来成就感。

方法四：先难后易还是先易后难？建议先做15分钟最容易的（进入状态），再做最难的（精力最好），最后做机械性的（抄写、背诵）。

计划执行不下去时，不要推翻重来，只调整明天的那一页。计划是工具，不是用来责备自己的尺子。
