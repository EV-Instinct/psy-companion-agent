# 父母不理解我，还要不要沟通
> 关键词：代沟、理解、沟通、失望

"说了他们也不懂""他们只会说'这有什么好难过的'"——当沟通反复受挫，人会选择沉默。但沉默久了，误会会更深。

可以试试"降级沟通"：不追求"完全被理解"，先追求"被听见一点"。

一，从"感受"开始，不从"道理"开始。父母更容易接住"我今天很难受"，而不是"你们的教育方式有问题"。

二，用具体的例子。不说"你们从来不关心我"，说"上次我说考试紧张，你们说'这有什么好紧张的'，我当时挺失落的"。

三，挑对时机。饭桌上、睡前、双方都累的时候都不适合深谈。散步、开车、一起做家务时反而更容易开口。

四，降低期待。父母也是普通人，有他们的成长背景和局限。他们可能永远说不出你想听的那句话，但这不代表不爱你。

五，找"替代性理解"。老师、亲戚、朋友、心理老师，都可以成为你的支持系统。不必把"被理解"的全部希望压在一两个人身上。

如果沟通中出现羞辱、威胁、暴力，停止沟通，先保护自己，再求助。
