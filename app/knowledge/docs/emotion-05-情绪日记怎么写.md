# 情绪日记：每天五分钟，看清自己的情绪
> 关键词：情绪日记、记录、觉察、方法

情绪日记不是作文，不用写得好，只要写得真。每天睡前五分钟，回答四个问题：

一，今天最强烈的一次情绪是什么？（紧张、生气、委屈、开心……）

二，当时发生了什么？（一句话就行，比如"数学小测发了卷子"）

三，我当时脑子里在想什么？（"我完了""他们都在看我"）

四，我后来做了什么？身体有什么感觉？（"我趴在桌上没说话，胸口闷"）

坚持两周，你会看到一些规律：比如"每次提到排名我就特别慌""每次和妈妈说话前我就开始紧张"。看见规律，是改变的第一步。

进阶版：在第四条后面加一句"如果重来一次，我可以怎么做"。不用逼自己想出完美答案，想到一个就写一个。

小提醒：情绪日记是给自己看的，不用给任何人检查。如果写的时候情绪很激动，可以先停一停，做几次呼吸再写。
