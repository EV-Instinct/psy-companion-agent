# 单亲家庭、父母离异，我该怎么办
> 关键词：单亲、离异、家庭变化、安全感、自责

父母分开，对孩子来说往往像"家塌了一半"。难过、愤怒、羞耻、害怕，都是正常的。

先说三件常被误解的事：

一，父母分开不是你的错。大人的感情问题有复杂的原因，和你乖不乖、成绩好不好没有关系。

二，你不需要选边站。你可以同时爱爸爸和妈妈，不需要为了"忠诚"而贬低另一方。

三，家里少了一个人，不等于爱少了一半。很多单亲家庭的孩子一样长得很好，关键是有没有稳定的支持和规律的照顾。

你可以做的事：
一，允许自己难过，也允许自己偶尔开心。开心不代表忘记，难过也不代表脆弱。
二，保持稳定的生活节奏：固定的作息、学习、运动、见朋友。稳定感能对冲家庭变化带来的不安。
三，找一个可以说心里话的人：亲戚、老师、心理老师、12355。
四，如果父母在你面前说对方坏话，你可以说"我不想听这些，你们的事你们自己解决"。

如果出现持续的情绪低落、失眠、不想上学，请告诉信任的大人，寻求专业帮助。
