# 摇号、分班、择校：面对不确定的结果
> 关键词：升学、摇号、分班、不确定、等待焦虑

升学季有很多"等结果"的时刻：摇号、分班考、录取通知。等待的过程最磨人，因为结果不在自己手里。

面对不确定，可以做三件事：

一，把"担心"和"能做的事"分开。拿一张纸，左边写"我控制不了的"（摇号结果、别人怎么排、政策怎么变），右边写"我能做的"（准备好材料、了解学校信息、保持作息）。把注意力放在右边。

二，给等待设一个"担心时间"。每天固定10分钟专门想这件事，其他时间想起时告诉自己"留到担心时间再想"。这能减少全天被焦虑占据。

三，准备"两种结果的预案"。想一想：如果去了A学校，我要做什么；如果去了B学校，我要做什么。预案不是诅咒，是让自己知道"无论哪种结果，我都有路走"。

还有一点很重要：学校重要，但没有重要到决定一生。真正影响你的，是你在任何一所学校里，愿不愿意认真学、愿不愿意交朋友、愿不愿意求助。
