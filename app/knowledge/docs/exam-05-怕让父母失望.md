# 总怕让爸爸妈妈失望怎么办
> 关键词：父母期待、失望、压力、沟通、自我价值

"如果我考不好，爸妈会不会不爱我了"——很多六年级同学心里都有这句话，只是不敢说。

先看清一件事：父母的期待，往往来自他们自己的焦虑（怕你以后吃苦），表达方式常常很笨拙。他们的失望，不等于不爱；但他们的表达，确实会让你难受。这两件事可以同时成立。

三个可以尝试的做法：

一，把担心说出来。找一个双方都不急的时候，说："我知道你们希望我考好，我也希望。但你们一说'你怎么又这样'，我就特别慌，越慌越学不进去。"说感受，不指责。

二，给父母一个"具体的你"。很多父母只看到分数，看不到你每天的努力。可以主动说："我今天复习了40分钟数学，错题订正了5道。"让他们看见过程，而不只是结果。

三，给自己留一块"不靠成绩证明"的地方。一项喜欢的运动、一个擅长的小事、一个能说心里话的朋友——这些都在提醒你：你不只是分数。

如果父母的话已经让你长期睡不着、不想回家，一定要告诉老师或拨打12355。你不需要独自承受。
