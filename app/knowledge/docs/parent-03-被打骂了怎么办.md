# 被父母打骂了，怎么办
> 关键词：打骂、家暴、安全、求助、12355

先说最重要的一句：被打不是你的错，任何人（包括父母）都没有权利对你实施暴力。

如果正在发生危险：
一，先保护自己。离开现场，去有其他人的地方，或者反锁房间。
二，找可信的大人。邻居、亲戚、老师、社区工作人员，告诉他们发生了什么。
三，紧急情况拨打110。这不是"不孝"，是保护自己。

如果已经被打骂，事后可以做的事：
一，留下记录。拍照、记下时间，必要时有用。
二，告诉一个成年人。班主任、心理老师、亲戚，任何你信任的人。
三，拨打12355青少年服务台或12338妇女维权热线，咨询怎么处理。

关于"打是亲骂是爱"：这是错误的观念。管教可以有边界，暴力没有。经常性的打骂、羞辱、威胁，属于需要干预的家庭暴力。

如果你暂时还得住在家里，尽量减少冲突：不在对方情绪激动时顶嘴，保护好自己，同时找到一个可以说话的人。你不需要独自承受。
