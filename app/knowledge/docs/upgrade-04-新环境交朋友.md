# 到了新学校，怎么交到朋友
> 关键词：初中、新环境、交朋友、社交、主动

新学校交朋友，靠的不是"会说话"，而是"会出现"和"敢开口"。

几个具体的方法：

一，利用"重复见面"效应。心理学发现，人会对经常见到的人更有好感。固定坐同一个位置、参加同一个社团、课间去同一个地方，见面多了，自然会有话聊。

二，用"小请求"破冰。比起"我们做朋友吧"，更自然的是"这道题你会吗""你知道食堂在哪吗"。请求帮助会让对方感到被需要，是建立关系的捷径。

三，记住名字。开学第一周，努力记住周围五个同学的名字，下次见面叫出来，对方会明显更亲近。

四，找到"同类"。喜欢画画的找美术社，喜欢篮球的找球场，喜欢看书的找图书馆。共同兴趣是最好的社交货币。

五，允许"慢热"。不是每个人第一天就能交到好朋友。有些友谊要一两个月才熟起来，这很正常。

如果开学一个月还是一个人、被孤立甚至被欺负，一定要告诉班主任或家长。交朋友是技能，不是天赋，可以学，也可以求助。
